# Weather-Aware Truck Routing Frontend

This directory is reserved for the React client application.

## Recommended Stack
- **Framework**: React 18/19 with Vite + TypeScript
- **Mapping & Geospatial**: Mapbox GL JS / Deck.gl
- **State & Polling**: TanStack Query (React Query)
- **Styling**: Modern responsive CSS / TailwindCSS / Lucide icons

## Integration
The frontend will communicate with the Django backend at `/api/route/` for asynchronous job submission and polling.
